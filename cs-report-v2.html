Setup Supabase

Sambungkan webapp ke database Supabase supaya semua staf kongsi data yang sama.

⚠️ Lakukan setup ini sekali sahaja oleh admin/pengurus. Selepas disimpan, semua staf boleh guna tanpa setup semula.
🔑
Masukkan Credentials Supabase
📋
Panduan Setup Langkah Demi Langkah
1
Buat akaun Supabase (percuma)
Pergi ke supabase.com → klik Start your project → daftar dengan Google atau email. Akaun percuma sudah cukup (500MB).
2
Buat projek baru
Klik New Project → pilih nama (contoh: cs-ngo-report) → set password database → pilih region Southeast Asia (Singapore) → klik Create new project. Tunggu 1-2 minit.
3
Buat table dalam database
Di dashboard Supabase → klik SQL Editor (ikon terminal) → klik New query → copy-paste SQL di bawah → klik Run.
CREATE TABLE cs_daily_reports ( id uuid DEFAULT gen_random_uuid() PRIMARY KEY, report_date date NOT NULL, staff_name text NOT NULL, shift text, wa1_masuk int DEFAULT 0, wa1_engaged int DEFAULT 0, wa2_masuk int DEFAULT 0, wa2_engaged int DEFAULT 0, wa3_masuk int DEFAULT 0, wa3_engaged int DEFAULT 0, em1_masuk int DEFAULT 0, em1_engaged int DEFAULT 0, em2_masuk int DEFAULT 0, em2_engaged int DEFAULT 0, notes text, created_at timestamptz DEFAULT now() ); ALTER TABLE cs_daily_reports ENABLE ROW LEVEL SECURITY; CREATE POLICY "Allow all" ON cs_daily_reports FOR ALL USING (true) WITH CHECK (true);
4
Dapatkan URL dan API Key
Di dashboard Supabase → klik Project Settings (gear icon) → klik API → copy dua nilai:

• Project URL — contoh: https://abcdefgh.supabase.co
• anon public key — bermula dengan eyJ...
5
Masukkan credentials di atas
Paste URL dan Key dalam borang di atas → klik Simpan & Test Sambungan. Kalau berjaya, badge header akan tukar kepada hijau ✅.
6
Deploy ke Cloudflare Pages
1. Pergi ke pages.cloudflare.com → Log in / daftar percuma
2. Klik Create a project → pilih Direct Upload
3. Nama projek: cs-ngo-report → klik Create project
4. Upload fail cs-report-v2.html → rename jadi index.html sebelum upload
5. Klik Deploy site
6. URL anda akan jadi: cs-ngo-report.pages.dev

Nota penting: Credentials Supabase disimpan dalam localStorage setiap browser. Staf perlu buka Setup tab dan masukkan credentials sekali pada device masing-masing.
